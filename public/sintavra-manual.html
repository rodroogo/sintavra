#include <stdio.h>

Un array agrupa elementos contiguos del mismo tipo. Su tamaño no crece con append. sizeof calcula bytes; la división mostrada calcula elementos solo cuando notas es realmente un array en ese ámbito.

#include <stdio.h>
int main(void) {
    int notas[] = {12, 16, 18};
    size_t cantidad = sizeof notas / sizeof notas[0];

}

Los arrays no verifican límites. sizeof sobre un parámetro puntero no revela el tamaño del array.

El for clásico tiene inicio, condición y actualización. Para recorrer los valores de un array también existe for...of. for...in recorre claves y no es su equivalente.

for (let i = 1; i <= 5; i++) {
  console.log(i);
}

Usar <= notas.length como límite puede intentar leer un elemento inexistente.

English · Repeating with for

A loop repeats a block. Trace its initial state, continuation condition and update. Always verify where it stops. The classic for has initialization, condition and update. The condition is checked before every iteration.

Funciones

Una función puede recibir parámetros y devolver un resultado con return. Si llega al final sin return, devuelve undefined. La función puede llamarse varias veces con distintos argumentos.

function doble(numero) {
  return numero * 2;
}
console.log(doble(7));

console.log muestra un valor pero no lo devuelve al código que llama.

English · Functions

A function groups a reusable operation. Parameters receive inputs; return supplies a result to the caller. Printing and returning are different.

Repetir con for

El for numérico incluye el límite final cuando el paso permite alcanzarlo. for i = 1, 5 recorre 1 a 5. Un tercer valor permite elegir el paso.

for i = 1, 5 do
    print(i)
end

El límite de este for es inclusivo, a diferencia del stop de range en Python.

Repetir con for

range(1, 6) produce 1, 2, 3, 4 y 5: el límite final se excluye. for recorre elementos de un iterable. No necesita un contador que incrementes a mano.

for numero in range(1, 6):
    print(numero)

range(5) empieza en cero. Para incluir 5 como último número, el límite debe ser 6.

print(notas[0])
print(len(notas))

El último índice es len(notas) - 1, no len(notas).
